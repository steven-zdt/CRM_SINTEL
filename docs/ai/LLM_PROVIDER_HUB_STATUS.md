## Por qué se detiene aquí

El propio plan (§53, "Primera Misión") exige: "La IA editora NO debe empezar modificando producción. Primero ejecutar FASE 0... Después continuar secuencialmente por fases." Fase 0 completa. Las Fases 1+ implican trabajo real y sustancial (modelos de datos nuevos + migraciones, UI completa en `/console/`, gestión de secretos, resolver central que toca `agent.py`) -- no configuración, sino feature nuevo. Se retoma fase por fase cuando el usuario lo pida explícitamente, mismo criterio ya aplicado con `docs/ai/OLLAMA_STATUS.md`.

## Regla de honestidad de este tracker

No se avanza una fase con `FAIL`. No se declara `PASS` sin evidencia enlazada -- mismo criterio que `ADK_STATUS.md`/`OLLAMA_STATUS.md`.
