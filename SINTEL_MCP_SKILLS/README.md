Suite de skills Markdown para el MCP Control Plane de SINTEL ERP.

Orden recomendado: 00 master → 01 discovery → 02 CRUD → 03 acciones → 04 seguridad → 05 integridad → 06 tests → 07 repair → 08 matriz → 09 loop → 10 catálogo → 11 implementación.
